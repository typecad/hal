# RP2040 + RP2350 Board Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two board targets (`rp2040` for Raspberry Pi Pico, `rp2350` for Pico 2) — the first non-ESP32/non-AVR boards, using ARM Cortex-M silicon with the earlephilhower Arduino core.

**Architecture:** Four new packages mirroring the established two-layer MCU+board split. The RP2040 needs zero framework edits (already fully anticipated); the RP2350 needs 5 (union, profile, capability map). Neither uses `IRAM_ATTR` or `freeHeap()` — those are ESP32-family-only checks. Pin naming uses `GP<n>` (not `GPIO<n>`).

**Tech Stack:** TypeScript monorepo, vitest, the cuttlefish schema, `@typecad/hal` Pin helpers.

**Spec:** `docs/superpowers/specs/2026-07-07-rp2040-rp2350-board-support-design.md`

**Reference template:** `packages/mcu-esp32c3/` and `packages/board-esp32c3/` — same file structure, closest analog (single-core, no touch, no PSRAM). Differences: GP prefix, no wireless peripherals, different FQBN pattern, no IRAM_ATTR.

- [ ] **Step 5: Create `packages/mcu-rp2040/src/index.ts`**

The MCUDefinition. Key data:
- 30 GPIO (GP0–GP29). GP0–GP22: FULL_GPIO (GP26–29: FULL_GPIO_ANALOG for ADC). GP23–25, GP29: unsafe (internal flash/LED).
- ADC channels on GP26–29. Bus functions on GP0/1 (UART0), GP4/5 (I2C0), GP16–19 (SPI0).
- Memory: flash 2 MB, sram 264 KB (270336 bytes). No externalRam.
- Features: multicore true, coreCount 2, fpu false (M0+ has no FPU).
