Rename `@typehal/transpiler` → `@typecad/cuttlefish`. Absorb `@typehal/core` and `@typehal/schema` into it. Rename all `@typehal/*` packages to `@typecad/*`. No backward compatibility maintained.

### Transpiler internal import path calculation

For the ~92 files in cuttlefish that currently import from `@typehal/core`, the new import path depends on file depth:

```
src/*.ts           → "./api" or "./api/shared" or "./api/schema"
src/*/*.ts         → "../api" or "../api/shared" or "../api/schema"
src/*/*/*.ts       → "../../api" or "../../api/shared" or "../../api/schema"
```

This requires per-file relative path calculation. Each file's existing `@typehal/core` import must be mapped to the correct relative path to `api/`, `api/shared/`, or `api/schema/`.
